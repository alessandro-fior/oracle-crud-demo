# Database & SQL Documentation - Oracle CRUD Demo

Questa cartella contiene gli script DDL/DCL e la documentazione completa di tutte le query SQL eseguite dall'applicazione Spring Boot sul database Oracle.

## Avvio Docker e ripristino guidato (Oracle XE attuale)

Per la procedura persistente completa con comandi per avviare, entrare, verificare e fermare il container, vedere [`DOCKER_XE_GUIDA.md`](DOCKER_XE_GUIDA.md).

Aprire CMD nella cartella del progetto (`C:\projects\oracle-crud-demo`) ed eseguire:

```cmd
docker compose up -d oracle
docker compose ps
docker logs -f oracle-demo
```

Attendere nel log `DATABASE IS READY TO USE!`, quindi premere `Ctrl+C` per uscire dalla visualizzazione dei log (il container resta attivo). Entrare in SQL*Plus nel container:

```cmd
docker exec -it oracle-demo sqlplus system/demo_pass@XEPDB1
```

Al prompt `SQL>` eseguire lo script montato? Il file del progetto non è montato nel container, quindi usare invece il blocco PL/SQL sotto oppure aprire SQL*Plus dall'host con SQLcl. Il metodo semplice è DBeaver: collegarsi come `SYSTEM` a `localhost:1521/XEPDB1`, aprire `00_verifica_ripristino.sql` ed eseguirlo come script.

Con SQLcl installato sull'host, dalla cartella progetto si può eseguire direttamente:

```cmd
sql system/demo_pass@localhost:1521/XEPDB1 @sql/00_verifica_ripristino.sql
```

Lo script `00_verifica_ripristino.sql` crea `CLIENTE` e `CLIENTE.CLIENTE` se mancanti e imposta la password dell'utente applicativo a `Cliente1234!`; non elimina dati già presenti. DBeaver e l'applicazione usano host `localhost`, porta `1521`, servizio `XEPDB1`.

## 1. Parametri di Connessione

| Parametro | Connessione DBA (Setup) | Connessione Applicativa (Spring Boot) |
| :--- | :--- | :--- |
| **Host** | `localhost` | `localhost` |
| **Porta** | `1521` (o porta alternativa, es. `1522`) | `1521` (o porta alternativa, es. `1522`) |
| **Service Name** | `FREEPDB1` (Pluggable Database) | `FREEPDB1` (Pluggable Database) |
| **Username** | `SYSTEM` | `CLIENTE` |
| **Password** | `oracle` | `oracle` |
| **JDBC URL** | `jdbc:oracle:thin:@localhost:1521/FREEPDB1` | `jdbc:oracle:thin:@localhost:1521/FREEPDB1` |

> [!NOTE]
> Su Oracle Database (12c, 19c, 21c, 23ai/26ai Free) gli utenti applicativi vanno creati all'interno del **PDB** (`FREEPDB1`) e non nel container root (`CDB$ROOT`).

## 2. Script di Inizializzazione

Gli script vanno eseguiti in ordine sequenziale:

### 2.1. `01_schema.sql` (Eseguito come DBA / `SYSTEM`)
Crea l'utente applicativo `CLIENTE`, assegna i privilegi necessari per connettersi e creare oggetti, e definisce la quota sul tablespace `USERS`.

```sql
-- 01_schema.sql
-- Connettersi al PDB FREEPDB1 come utente SYSTEM (o DBA)
CREATE USER CLIENTE IDENTIFIED BY oracle;
GRANT CREATE SESSION, CREATE TABLE, CREATE SEQUENCE TO CLIENTE;
ALTER USER CLIENTE QUOTA UNLIMITED ON USERS;
```

### 2.2. `02_tables.sql` (Eseguito come `CLIENTE`)
Crea la tabella `cliente` con chiave primaria numerica autoincrementale (tramite clausola `IDENTITY` nativa Oracle 12c+).

```sql
-- 02_tables.sql
-- Connettersi al PDB FREEPDB1 come utente CLIENTE
CREATE TABLE cliente (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR2(50) NOT NULL,
    cognome VARCHAR2(50) NOT NULL,
    email VARCHAR2(100),
    telefono VARCHAR2(20)
);
```

## 3. Query SQL Eseguite dall'Applicazione (Spring Boot / JDBC)

Le seguenti query vengono eseguite tramite [`ClienteRepository`](file:///c:/projects/oracle-crud-demo/src/main/java/com/example/oraclecrud/repository/ClienteRepository.java) usando `JdbcTemplate` e `NamedParameterJdbcTemplate`:

### 3.1. Creazione Cliente (Create / INSERT)
- **Metodo Java:** `save(Cliente c)`
- **Endpoint:** `POST /api/clienti`
- **Descrizione:** Inserisce un nuovo record. L'ID viene generato automaticamente dal database (`IDENTITY`) e recuperato tramite `statement.getGeneratedKeys()`.

```sql
INSERT INTO cliente (nome, cognome, email, telefono)
VALUES (?, ?, ?, ?)
```

**Esempio di query con valori reali:**
```sql
INSERT INTO cliente (nome, cognome, email, telefono)
VALUES ('Mario', 'Rossi', 'mario@example.com', '+390123456');
```

---

### 3.2. Lettura Tutti i Clienti (Read All / SELECT)
- **Metodo Java:** `findAll()`
- **Endpoint:** `GET /api/clienti`
- **Descrizione:** Recupera l'elenco completo dei clienti ordinati per record inseriti.

```sql
SELECT id, nome, cognome, email, telefono 
FROM cliente;
```

---

### 3.3. Lettura Singolo Cliente per ID (Read by ID / SELECT)
- **Metodo Java:** `findById(Long id)`
- **Endpoint:** `GET /api/clienti/{id}`
- **Descrizione:** Recupera i dati del cliente specificato dal parametro `:id`.

```sql
SELECT id, nome, cognome, email, telefono 
FROM cliente 
WHERE id = :id;
```

**Esempio di query con valore reale:**
```sql
SELECT id, nome, cognome, email, telefono 
FROM cliente 
WHERE id = 1;
```

---

### 3.4. Aggiornamento Cliente (Update / UPDATE)
- **Metodo Java:** `update(Cliente c)`
- **Endpoint:** `PUT /api/clienti/{id}`
- **Descrizione:** Aggiorna i campi del record corrispondente all'ID specificato.

```sql
UPDATE cliente 
SET nome = :nome, 
    cognome = :cognome, 
    email = :email, 
    telefono = :telefono 
WHERE id = :id;
```

**Esempio di query con valori reali:**
```sql
UPDATE cliente 
SET nome = 'Mario', 
    cognome = 'Rossi', 
    email = 'nuovo@example.com', 
    telefono = '+390987654' 
WHERE id = 1;
```

---

### 3.5. Cancellazione Cliente (Delete / DELETE)
- **Metodo Java:** `delete(Long id)`
- **Endpoint:** `DELETE /api/clienti/{id}`
- **Descrizione:** Elimina fisicamente il record con l'ID fornito.

```sql
DELETE FROM cliente 
WHERE id = :id;
```

**Esempio di query con valore reale:**
```sql
DELETE FROM cliente 
WHERE id = 1;
```

## 4. Modalità di Esecuzione degli Script

### Opzione A: Tramite SQLcl / SQL*Plus da riga di comando

```bash
# 1. Creazione schema (eseguire come SYSTEM)
sql system/oracle@localhost:1521/FREEPDB1 @sql/01_schema.sql

# 2. Creazione tabella (eseguire come CLIENTE)
sql CLIENTE/oracle@localhost:1521/FREEPDB1 @sql/02_tables.sql
```

### Opzione B: Tramite Docker CLI

Se il database gira all'interno del container Docker `oracle`:

```bash
# Esecuzione script 01_schema.sql nel container
docker exec -i oracle sqlplus system/oracle@FREEPDB1 < sql/01_schema.sql

# Esecuzione script 02_tables.sql nel container
docker exec -i oracle sqlplus CLIENTE/oracle@FREEPDB1 < sql/02_tables.sql
```

### Opzione C: Tramite DBeaver / Oracle SQL Developer / VS Code
1. Creare una connessione con:
   - **Host:** `localhost`
   - **Porta:** `1521` (o `1522`)
   - **Service Name:** `FREEPDB1`
   - **User / Password:** `SYSTEM` / `oracle`
2. Eseguire lo script `01_schema.sql`.
3. Creare una nuova connessione con lo user `CLIENTE` / `oracle`.
4. Eseguire lo script `02_tables.sql`.

## 5. Query Utili di Verifica e Manutenzione

### Verifica permessi e stato utente (come `SYSTEM`):
```sql
-- Verifica stato account utente CLIENTE
SELECT username, account_status, default_tablespace, created 
FROM all_users 
WHERE username = 'CLIENTE';

-- Verifica quota tablespace
SELECT tablespace_name, bytes, max_bytes 
FROM user_ts_quotas;
```

### Ispezione struttura tabella e colonna IDENTITY (come `CLIENTE`):
```sql
-- Dettagli colonne
SELECT column_name, data_type, data_length, nullable 
FROM user_tab_columns 
WHERE table_name = 'CLIENTE';

-- Dettagli colonna IDENTITY generata
SELECT table_name, column_name, generation_type, identity_options 
FROM user_tab_identity_cols 
WHERE table_name = 'CLIENTE';
```

### Query dirette di controllo dati:
```sql
-- Conteggio totale record
SELECT COUNT(*) AS totale_clienti FROM cliente;

-- Ultimi record inseriti
SELECT * FROM cliente ORDER BY id DESC;
```

### Reset / Pulizia dati tabella:
```sql
-- Svuotare la tabella azzerando anche l'identity/sequenza
TRUNCATE TABLE cliente;

-- Oppure eliminazione completa tabella
DROP TABLE cliente PURGE;
```
